# Happy / Sunny Theme

Theme asset folder for the Little Signs Happy / Sunny design.

## Suggested structure
- `thumbnail.png` — theme picker thumbnail
- `sign-background.png` — 8.5 × 11 sign background
- `nametag.png` — matching 3.5 × 1.5 student name tag
- `empty-placeholder.png` — matching empty name-tag parking space
- `child-silhouette.png` — capacity child visual, if theme-specific
- `centers/` — center artwork for this theme

Center artwork should use transparent backgrounds and consistent sizing/placement across the set.
