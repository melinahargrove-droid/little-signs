# Little Signs

Little Signs is a classroom center-sign generator for teachers.

## v0.1 prototype

The first build focuses on the core workflow:

- Enter and save a class list in the browser.
- Add common classroom centers or create custom centers.
- Set a different capacity for every center.
- Preview a center sign inspired by a practical preschool center-choice layout.
- Automatically create one name-card space per available center spot.
- Generate matching student name tags.
- Print the current center sign or the class name-tag sheet.
- Store the current classroom setup locally on the device using `localStorage`.

## Product rule

**Capacity controls layout, not scale.**

As the capacity changes, Little Signs changes the arrangement of the choice-card spaces instead of simply shrinking one fixed layout.
